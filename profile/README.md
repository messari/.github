# Messari is now part of Blockworks

The Messari API, MCP server, and datasets continue, unified under Blockworks.

- Code: [github.com/Blockworks-Projects](https://github.com/Blockworks-Projects)
- Docs: [docs.blockworks.com](https://docs.blockworks.com)
- API keys: [app.blockworks.com/account/api](https://app.blockworks.com/account/api)

Repositories in this organization target the legacy Messari API. They are in maintenance mode while existing customers migrate: critical fixes only, no new features. New work lands in the [Blockworks API](https://docs.blockworks.com).
